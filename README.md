## Put it live on GitHub Pages (free, phone-doable, Sana does this part)
1. On your phone, open github.com and sign in (create a free account first if you don't have one — no card needed).
2. Tap + → New repository. Name it `ss-and-co-games-website`. Make it Public. Tap Create repository.
3. On the new empty repo page, tap "uploading an existing file" and upload `index.html` and the 5 images in `images/` (keep the folder name `images`).
4. Tap Commit changes.
5. Go to Settings → Pages. Under "Build and deployment", Source: Deploy from a branch. Branch: main, folder: / (root). Tap Save.
6. Wait 1–2 minutes. Your free address will be:
   `https://YOUR-GITHUB-USERNAME.github.io/ss-and-co-games-website/`
   (replace YOUR-GITHUB-USERNAME with your GitHub username)

That address is free forever for this kind of page. It is a subdomain, not a `.com`
— a real `.com` always costs money every year.
